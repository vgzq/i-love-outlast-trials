Features:

Apply my config that reduces graphical effects and improve FPS

Set custom resolution and frame rate cap

Backup and restore config files

Optional read-only protection for config files

Usage:

1. Run the script as Administrator

2. Enter the folder path containing Engine.ini and GameUserSettings.ini. (usually found in "%appdata%\Local\OPP\Saved\Config\WindowsClient")

3. Optionally create a backup

4. select whatever option you wanna use :3
